# EZ9010 Unsupported\_Operator

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: operator name, operator type.

```text
No parser is registered for Op [%s, optype [%s]].
```

Error example:

```text
No parser is registered for Op [Conv2D_1, optype [Conv2D]].
```

## Solution

Submit an issue to request for support at https://gitcode.com/cann/opbase/issues.
